# Конструктор геометрии велосипеда — спецификация

Дата: 2026-10-14. Статус: на ревью.

## Цель

Браузерный конструктор геометрии **одной** велосипедной рамы (в духе bikeinsights.com). Пользователь
правит любой параметр, видит боковой чертёж и производные величины. Любое поле можно **закрепить** —
при правке другого поля закреплённые сохраняют значение, остальные пересчитываются. Состояние живёт в URL.

Успех: правка любого поля за <50 мс даёт согласованную геометрию, закреплённые поля не дрейфуют
(точность 0.01 мм / 0.01°), ссылка восстанавливает ровно то же состояние.

Вне скоупа: сравнение рам, посадка райдера, дюймы, библиотека пресетов, бэкенд.

## Стек

Vite + TypeScript (strict) + Vitest. Рендер — чистый SVG, без UI-фреймворка. Только dev-зависимости.
Старые `index.html`, `script.js`, `styles.css` удаляются.

## Модель

Система координат: каретка (BB) в начале, x — вперёд, y — вверх, мм и градусы.

### Базовые параметры (независимые)

| ключ | поле | по умолч. | решатель меняет? |
|---|---|---|---|
| `stack` | Stack | 560 | да |
| `reach` | Reach | 385 | да |
| `headAngle` | Угол рулевой (HTA), ° от горизонта | 73 | да |
| `seatAngle` | Эфф. угол подседельной (STA), ° | 73.5 | да |
| `headTube` | Длина рулевой | 150 | да |
| `chainstay` | Длина перьев (ось–каретка) | 410 | да |
| `bbDrop` | BB drop | 70 | да |
| `forkOffset` | Офсет вилки | 45 | да |
| `lowerStack` | Нижний стек рулевой колонки | 10 | нет |
| `seatTube` | Длина подседельной (ц–верх) | 520 | да |
| `rimFront` | Посадочный диаметр переднего обода (BSD) | 622 | нет |
| `rimRear` | Посадочный диаметр заднего обода (BSD) | 622 | нет |
| `tireFront` | Ширина (≈высота) передней шины | 28 | нет |
| `tireRear` | Ширина (≈высота) задней шины | 28 | нет |

«Нет» — параметр меняется только прямым вводом, решатель его не трогает.

### Точки

- `htTop = (reach, stack)`; ось руления из `htTop` вниз-вперёд: `u = (cos HTA, −sin HTA)`.
- `htBottom = htTop + headTube·u`.
- Радиусы колёс `Rf = rimFront/2 + tireFront`, `Rr = rimRear/2 + tireRear`. `bbDrop` измеряется от задней оси: задняя ось на `y = bbDrop`, передняя на `y = bbDrop + Rf − Rr`. Земля `y = bbDrop − Rr`.
- `rearAxle = (−√(chainstay² − bbDrop²), bbDrop)`.
- Перпендикуляр вперёд `n = (sin HTA, cos HTA)`. Передняя ось = `htTop + t·u + forkOffset·n`, где
  `t = (stack + forkOffset·cos HTA − (bbDrop + Rf − Rr)) / sin HTA`.
- `seatTop = seatTube·(−cos STA, sin STA)`.

### Производные (вычисляемые) поля

| ключ | формула |
|---|---|
| `forkLength` | `t − headTube − lowerStack` (ось–коронка вдоль оси руления) |
| `trail` | x пересечения оси руления с землёй − x передней оси |
| `wheelbase` | `frontAxle.x − rearAxle.x` |
| `totalLength` | `frontAxle.x + Rf − (rearAxle.x − Rr)` |
| `frontCenter` | `hypot(frontAxle.x, frontAxle.y)` — прямое расстояние от BB до передней оси (как у производителей) |
| `bbHeight` | `Rr − bbDrop` |
| `chainstayAngle` | `asin(bbDrop / chainstay)`, ° |
| `effectiveTopTube` | `reach + stack / tan STA` |
| `topTubeAngle` | угол линии seatTop → htTop к горизонту, ° |
| `standover` | (seatTop.y + htTop.y)/2 − groundY |

### Валидность

Геометрия невалидна, если: угол вне (45°, 90°], длина ≤ 0 (`headTube`, `chainstay`, `seatTube`,
`rimFront`, `rimRear`, `tireFront`, `tireRear`, `forkLength`), `chainstay ≤ |bbDrop|`, `bbHeight ≤ 0`, нечисловое значение.

## Решатель

`solve(base, edit: {key, value}, locks: Set<key>) → {ok: true, base} | {ok: false, error}`

- Переменные: базовые параметры с «решатель меняет = да», не закреплённые; если `edit.key` — базовый,
  он ставится сразу и тоже исключается. Углы масштабируются ×10 (1° ≈ 10 мм) для минимальной нормы.
- Ограничения: `f_edit(x) = value` (если edit — производное) и `f_lock(x) = текущее значение` для
  каждого закреплённого **производного** поля (закреплённые базовые просто исключены из переменных).
- Гаусс–Ньютон с минимальной нормой: `dx = −Jᵀ(JJᵀ)⁻¹g`, численный якобиан (центральная разность,
  h = 1e-4), ≤ 30 итераций, сходимость при `max|g| < 1e-6`.
- Ошибки (ввод откатывается, текст показывается у поля):
  - `overconstrained` — ограничений больше, чем переменных, или `JJᵀ` вырождена;
  - `unreachable` — нет сходимости;
  - `invalid` — результат невалиден по правилам выше.
- Нет ограничений (правка базового без закреплённых производных) → меняется только это поле.
- Закреплённое поле редактировать нельзя (input disabled).

## URL

Hash вида `#stack=560&reach=385&…&lock=trail,stack`. Пишется через `history.replaceState` после каждой
успешной правки. При загрузке: известные числовые ключи применяются поверх дефолтов, мусор игнорируется;
если итог невалиден — дефолты целиком. Неизвестные ключи в `lock` игнорируются.

## UI

Слева две группы полей: «Базовые», «Производные». Поле = подпись, `input type=number` (шаг 1 мм / 0.1°),
чекбокс-замок с `aria-label`. Применение по `change` (Enter/blur). Ошибка — текст под полем, `role=alert`,
пропадает при следующей успешной правке. Справа SVG-чертёж, viewBox подгоняется под рамку с отступом.

Чертёж: земля, оба колеса (окружности радиусов Rf, Rr), перья, верхние перья (`rearAxle → seatTop`),
подседельная, верхняя (`seatTop → htTop`), нижняя (`BB → htBottom`), рулевая, вилка
(`htBottom → коронка → передняя ось`), ось руления пунктиром до земли, отрезок trail на земле.
Цвета через CSS-переменные, тёмная тема по `prefers-color-scheme`.

## Модули

| файл | ответственность | зависит от |
|---|---|---|
| `src/geometry.ts` | типы, дефолты, `points(base)`, `derived(base)`, `field(base,key)`, `validate(base)` | — |
| `src/solver.ts` | `solve(...)`, маленький линейный решатель | geometry |
| `src/url.ts` | `encode(state)`, `decode(hash)` | geometry |
| `src/render.ts` | `render(svg, base)` | geometry |
| `src/main.ts` | DOM полей, связка всего | все |

## Тестирование (TDD, Vitest)

- `geometry`: аналитические случаи (HTA = 90° → trail = −forkOffset; offset = 0 → ось через
  переднюю ось; известный ручной расчёт дефолтов с допуском 0.01), валидность.
- `solver`: правка базового без замков меняет только его; правка производного (trail) достигает цели;
  закреплённые поля сохраняются (trail закреплён, меняем HTA → offset подстраивается); overconstrained;
  unreachable (свободен только `chainstay`, цель `wheelbase` < `frontCenter` → NaN, нет сходимости); invalid.
- `url`: round-trip, мусор → дефолты, неизвестные lock-ключи игнорируются.
- `render`/`main`: без юнит-тестов, ручная проверка во встроенном браузере (правки, замки, ошибки, URL,
  тёмная тема, ширина телефона).

Процесс: каждый модуль — отдельная задача для субагента, красный тест → минимальный код → зелёный.
