# 3D-вид велосипеда — спецификация

Дата: 2026-10-14. Дополняет `2026-10-14-bike-geometry-design.md` и `2026-10-14-rider-fit-design.md`.

## Цель

Переключатель «Схема / 3D» над чертежом. В режиме 3D — детализированная модель велосипеда, построенная из
той же геометрии, что и схема, и обновляемая при каждой правке. Вращение/приближение мышью и пальцами.

Вне скоупа: выбор типа руля, цвета рамы, экспорт модели, анимация.

## Зависимость

`three@0.186.1` (runtime) и `@types/three@0.186.0` (dev). Это первая runtime-зависимость проекта —
разрешено пользователем. three.js и всё 3D-кодовое грузятся **динамическим импортом только при первом
переключении на 3D**: начальная загрузка страницы не растёт. `OrbitControls` из `three/addons`.

## Система координат

Как в геометрии: BB в (0,0,0), x — вперёд, y — вверх, z — вбок (+z — сторона привода, правая), мм.
В сцене всё масштабируется ×0,001 (метры).

## Модель (`src/model3d.ts`, чистая функция)

`buildModel(b: Base, rider?: Rider): Part[]` — список деталей с размерами и положением; без three.js,
покрывается тестами.

Части и параметры (мм):

| деталь | положение / размеры |
|---|---|
| рулевая | `htTop → htBottom`, конус Ø 50 (низ) → Ø 40 (верх) |
| верхняя труба | `seatTop → htTop`, Ø 34 |
| нижняя труба | `BB → htBottom`, Ø 48 |
| подседельная | `BB → seatTop`, Ø 32 |
| каретка | цилиндр по z, Ø 46, ширина 68 |
| нижние перья ×2 | от дропаута `(rearAxle, z=±67)` к `(BB, z=±35)`, Ø 22 → Ø 16 |
| верхние перья ×2 | от дропаута `(rearAxle, z=±67)` к точке на подседельной на 40 мм ниже `seatTop`, z=±10, Ø 16 |
| дропауты ×2 | пластины 30×40×8 у задней оси |
| вилка | ноги ×2 (z=±50): от коронки вниз вдоль оси руления на 60 % `forkLength`, затем плавный изгиб к передней оси; Ø 32 → Ø 18; коронка; шток от коронки до верха проставок |
| проставки | 20 мм над `htTop` вдоль оси руления, Ø 40 |
| вынос | 100 мм, −6° к перпендикуляру к штоку, Ø 32 |
| руль-баранка | ширина 420 c–c, reach 80, drop 125; обмотка; ручки тормозов/шифтеров |
| колёса ×2 | центр в точке оси (z=0); обод: радиус `rim/2`, профиль 25×20; покрышка: тор с малым радиусом `tire/2` на радиусе `rim/2 + tire/2`, протектор; 28 спиц, 2-cross, фланцы втулки Ø 50 на z=±35; втулка, ось |
| диски ×2 | Ø 160, слева: перед z=−50, зад z=−62; калиперы на вилке и на нижнем пере |
| система | шатуны 172,5 мм (правый под 30° к горизонту вперёд, левый — противоположно), звёзды 50/34 с зубьями (шаг 12,7) на z=+43,5; педали |
| кассета | 11–34 (11,13,15,17,19,21,24,27,30,34) на задней втулке, z от +20 до +60 |
| задний переключатель | упрощённо: кронштейн у дропаута, 2 ролика |
| цепь | звенья вдоль касательных между большой звездой и звездой кассеты 17 (верхняя ветвь) и через ролики (нижняя) |
| подседельный штырь | вдоль линии подседельной от `seatTop` до седла, Ø 27,2 |
| седло | длина 270, ширина 140; верх на расстоянии `S` от BB вдоль линии подседельной: `S = 0,883 × inseam` при заданном росте, иначе `seatTube + 200` |

Каждая деталь — `Part` с `kind`, `id` и числовыми параметрами; рендер не вычисляет геометрию велосипеда
сам, только строит меши по `Part`.

## Рендер (`src/scene3d.ts`)

- `mount(container: HTMLElement): { update(parts: Part[]): void; dispose(): void }`.
- `WebGLRenderer` (antialias, тени), `PerspectiveCamera`, `OrbitControls` (вращение, зум, панорама, сенсор),
  направленный свет с тенями + полусферический, пол с мягкой тенью; фон и цвета материалов из CSS-токенов
  (светлая/тёмная тема).
- Материалы: рама — `--frame`, металл (сталь/алюминий) — серый с `metalness`, резина — тёмная матовая,
  обмотка/седло — тёмные.
- Повторяющиеся элементы (спицы, звенья, зубья, протектор) — `InstancedMesh` или слитая геометрия.
- `update` заменяет геометрию без пересоздания рендерера; ресайз по `ResizeObserver`; цикл рендера только
  при изменениях/взаимодействии (не 60 fps вхолостую).
- Нет WebGL → вместо канваса текст «3D недоступно в этом браузере», схема работает.

## UI

- Переключатель (две кнопки, `role="tablist"`/`aria-selected`) над областью чертежа; «Схема» по умолчанию.
- В режиме 3D SVG скрыт, на его месте контейнер 3D того же размера; подсказки к подписям чертежа в 3D
  не показываются (подписей нет). Поля, подсветка по росту и подсказки у полей работают как раньше.
- Выбор вида в URL: `view=3d` (нет параметра → схема).
- Пока three.js грузится — «Загрузка 3D…».

## Тестирование

- `model3d` (TDD): колёса в точках осей с радиусами из базовых параметров; нижняя труба `BB → htBottom`;
  ноги вилки заканчиваются в передней оси на z=±50; нижние перья от z=±67 у оси к z=±35 у каретки;
  высота седла при росте 178 см = 0,883 × 836,6 вдоль линии подседельной; без роста — `seatTube + 200`;
  все числа конечны для рамы по умолчанию, маллета и 20″.
- `url`: `view=3d` round-trip, мусор → схема.
- Рендер/UI — вручную в браузере: вид со всех сторон, обновление при правке, тёмная тема, 375 px,
  плавность вращения, отсутствие ошибок в консоли, размер начального бандла не вырос.
