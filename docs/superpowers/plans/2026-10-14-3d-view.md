# 3D-вид — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переключатель «Схема / 3D» и детализированная 3D-модель велосипеда, построенная из геометрии и обновляемая при каждой правке.

**Architecture:** Чистый `src/model3d.ts` превращает геометрию (и рост) в список деталей `Part[]` — тестируется без WebGL. `src/scene3d.ts` строит по `Part[]` меши three.js и управляет сценой. `main.ts` добавляет переключатель и подгружает `scene3d` динамическим импортом только при первом переходе в 3D. `url.ts` хранит `view=3d`.

**Tech Stack:** Vite 8, TypeScript 7 strict, Vitest 5, three@0.186.1 (+ @types/three@0.186.0).

**Spec:** `docs/superpowers/specs/2026-10-14-3d-view-design.md`

## Global Constraints

- Ветка `view-3d` от `main`; не пушить. Коммиты заканчиваются строкой `Co-Authored-By:` для своей модели.
- three.js — только через динамический `import()` из `main.ts`; статических импортов `three` вне `scene3d.ts` нет; `model3d.ts` не импортирует three.
- Координаты: BB (0,0,0), x вперёд, y вверх, z вбок (+z — сторона привода), мм; сцена масштабирует ×0,001.
- Размеры деталей — ровно из таблицы спеки (они в `model3d.ts`); рендер не считает геометрию велосипеда сам.
- Геометрия, решатель, подбор по росту не меняются. Цвета сцены — из CSS-токенов, светлая и тёмная тема.
- `npm test` и `npm run build` зелёные в конце каждой задачи.

## Review Focus

1. Начальная загрузка не тянет three.js: в `dist` основной чанк не содержит three (Task 4, шаг сборки — проверить размер/наличие отдельного чанка).
2. Правка поля в режиме 3D обновляет модель, не пересоздавая рендерер и не утекая памятью (Task 3/4, ручная проверка: 20 правок подряд, без роста памяти/ошибок).
3. Нет WebGL → понятный текст, схема и поля работают (Task 3, `mount` ловит ошибку контекста).
4. Ссылка с `view=3d` открывается сразу в 3D (Task 2 тест + Task 4 ручная проверка).
5. Маллет и 20″ колёса — модель без NaN и разрывов (Task 1 тесты).

```ts
import { derived, points, type Base, type Pt } from './geometry';
import { inseamMm, type Rider } from './fit';

export type V3 = [number, number, number];
export type Mat = 'frame' | 'metal' | 'dark';
export type Part =
  | { kind: 'tube'; id: string; path: V3[]; r: [number, number]; mat: Mat }
  | { kind: 'wheel'; id: 'frontWheel' | 'rearWheel'; center: V3; rim: number; tire: number; spokes: number; flangeZ: number }
  | { kind: 'disc'; id: string; center: V3; diameter: number }
  | { kind: 'ring'; id: string; center: V3; teeth: number }
  | { kind: 'box'; id: string; center: V3; size: V3; mat: Mat }
  | { kind: 'bar'; id: 'bar'; center: V3; width: number; reach: number; drop: number }
  | { kind: 'saddle'; id: 'saddle'; top: V3; length: number; width: number }
  | { kind: 'chain'; id: 'chain'; path: V3[] };

const rad = (d: number) => (d * Math.PI) / 180;
const v = (p: Pt, z = 0): V3 => [p.x, p.y, z];
const add = (p: Pt, dir: Pt, k: number): Pt => ({ x: p.x + dir.x * k, y: p.y + dir.y * k });
export const pitchRadius = (teeth: number) => 12.7 / (2 * Math.sin(Math.PI / teeth));
const COGS = [34, 30, 27, 24, 21, 19, 17, 15, 13, 11];

export function buildModel(b: Base, rider?: Rider): Part[] {
  const p = points(b);
  const d = derived(b);
  const a = rad(b.headAngle), s = rad(b.seatAngle);
  const up: Pt = { x: -Math.cos(a), y: Math.sin(a) }; // up the steering axis
  const seat: Pt = { x: -Math.cos(s), y: Math.sin(s) }; // up the seat line from BB
  const onSeat = (dist: number): Pt => add(p.bb, seat, dist);
  const parts: Part[] = [];
  const tube = (id: string, path: V3[], r: [number, number], mat: Mat = 'frame') => parts.push({ kind: 'tube', id, path, r, mat });

  // Frame
  tube('headTube', [v(p.htTop), v(p.htBottom)], [20, 25]);
  tube('topTube', [v(p.seatTop), v(p.htTop)], [17, 17]);
  tube('downTube', [v(p.bb), v(p.htBottom)], [24, 24]);
  tube('seatTube', [v(p.bb), v(p.seatTop)], [16, 16]);
  tube('bbShell', [[0, 0, -34], [0, 0, 34]], [23, 23]);
  const junction = onSeat(b.seatTube - 40);
  for (const [side, z] of [['R', 1], ['L', -1]] as const) {
    tube(`chainstay${side}`, [v(p.rearAxle, 67 * z), [0, 0, 35 * z]], [11, 8]);
    tube(`seatstay${side}`, [v(p.rearAxle, 67 * z), v(junction, 10 * z)], [8, 8]);
    parts.push({ kind: 'box', id: `dropout${side}`, center: v(p.rearAxle, 67 * z), size: [40, 30, 8], mat: 'frame' });
    // Fork: straight down the steering axis, then bends forward to the axle.
    const bend = add(p.crown, { x: -up.x, y: -up.y }, 0.6 * d.forkLength);
    tube(`fork${side}`, [v(p.crown, 50 * z), v(bend, 50 * z), v(p.frontAxle, 50 * z)], [16, 9]);
  }
  parts.push({ kind: 'box', id: 'forkCrown', center: v(p.crown), size: [40, 30, 120], mat: 'frame' });

  // Cockpit
  const spacerTop = add(p.htTop, up, 20);
  const clamp = add(p.htTop, up, 40);
  tube('spacers', [v(p.htTop), v(spacerTop)], [20, 20], 'dark');
  tube('steerer', [v(p.crown), v(add(p.htTop, up, 60))], [14, 14], 'metal');
  const stemAngle = Math.PI / 2 - a - rad(6); // −6° to the perpendicular of the steerer
  const stemEnd = add(clamp, { x: Math.cos(stemAngle), y: Math.sin(stemAngle) }, 100);
  tube('stem', [v(clamp), v(stemEnd)], [16, 16], 'dark');
  parts.push({ kind: 'bar', id: 'bar', center: v(stemEnd), width: 420, reach: 80, drop: 125 });

  // Wheels and brakes
  parts.push({ kind: 'wheel', id: 'frontWheel', center: v(p.frontAxle), rim: b.rimFront, tire: b.tireFront, spokes: 28, flangeZ: 35 });
  parts.push({ kind: 'wheel', id: 'rearWheel', center: v(p.rearAxle), rim: b.rimRear, tire: b.tireRear, spokes: 28, flangeZ: 35 });
  parts.push({ kind: 'disc', id: 'discFront', center: v(p.frontAxle, -50), diameter: 160 });
  parts.push({ kind: 'disc', id: 'discRear', center: v(p.rearAxle, -62), diameter: 160 });
  parts.push({ kind: 'box', id: 'caliperFront', center: [p.frontAxle.x - 55, p.frontAxle.y + 45, -58], size: [50, 30, 25], mat: 'metal' });
  parts.push({ kind: 'box', id: 'caliperRear', center: [p.rearAxle.x + 60, p.rearAxle.y + 40, -70], size: [50, 30, 25], mat: 'metal' });

  // Drivetrain
  parts.push({ kind: 'ring', id: 'chainring50', center: [0, 0, 47], teeth: 50 });
  parts.push({ kind: 'ring', id: 'chainring34', center: [0, 0, 40], teeth: 34 });
  COGS.forEach((t, i) => parts.push({ kind: 'ring', id: `cog${t}`, center: v(p.rearAxle, 20 + (i * 40) / (COGS.length - 1)), teeth: t }));
  const crankDir = { x: Math.cos(rad(-30)), y: Math.sin(rad(-30)) };
  const rightEnd = add(p.bb, crankDir, 172.5), leftEnd = add(p.bb, crankDir, -172.5);
  tube('crankR', [[0, 0, 52], v(rightEnd, 52)], [12, 9], 'metal');
  tube('crankL', [[0, 0, -52], v(leftEnd, -52)], [12, 9], 'metal');
  parts.push({ kind: 'box', id: 'pedalR', center: v(rightEnd, 107), size: [90, 15, 70], mat: 'dark' });
  parts.push({ kind: 'box', id: 'pedalL', center: v(leftEnd, -107), size: [90, 15, 70], mat: 'dark' });
  const pulleyTop: Pt = { x: p.rearAxle.x + 10, y: p.rearAxle.y - 45 };
  const pulleyBottom: Pt = { x: p.rearAxle.x + 10, y: p.rearAxle.y - 95 };
  parts.push({ kind: 'box', id: 'derailleur', center: [pulleyTop.x, (pulleyTop.y + pulleyBottom.y) / 2, 55], size: [25, 80, 12], mat: 'metal' });
  const ring = pitchRadius(50), cog = pitchRadius(17), cogZ = 20 + (6 * 40) / (COGS.length - 1);
  parts.push({ kind: 'chain', id: 'chain', path: [[0, ring, 47], [p.rearAxle.x, p.rearAxle.y + cog, cogZ], [p.rearAxle.x, p.rearAxle.y - cog, cogZ], v(pulleyTop, cogZ), v(pulleyBottom, cogZ), [0, -ring, 47], [0, ring, 47]] });

  // Seat
  const saddleDist = rider ? 0.883 * inseamMm(rider) : b.seatTube + 200;
  tube('seatpost', [v(onSeat(b.seatTube - 60)), v(onSeat(saddleDist - 40))], [13.6, 13.6], 'metal');
  parts.push({ kind: 'saddle', id: 'saddle', top: v(onSeat(saddleDist)), length: 270, width: 140 });
  return parts;
}
```

### Task 3: рендер — `src/scene3d.ts`

Задача дизайна: в плане — контракт, обязательные приёмы и критерии; меши пишет исполнитель (модель уровня sonnet/opus). Юнит-тестов нет (WebGL); проверка — ручная в Task 4.

**Files:** Create `src/scene3d.ts`

**Interfaces:** Consumes `Part`, `V3`, `pitchRadius` из `./model3d`. Produces:

```ts
export function mount(container: HTMLElement): { update(parts: Part[]): void; dispose(): void };
```

Требования:
- [ ] **Сцена:** `WebGLRenderer({ antialias: true })`, `shadowMap.enabled`, `outputColorSpace = SRGBColorSpace`, pixelRatio ≤ 2; `PerspectiveCamera(35°)`, начальный вид — 3/4 спереди справа, вся модель в кадре; `OrbitControls` (damping, min/max distance, нельзя уйти под пол); `HemisphereLight` + `DirectionalLight` с тенями; пол — `PlaneGeometry` с `ShadowMaterial`/цветом панели; весь велосипед в группе, масштаб 0,001.
- [ ] **Цвета:** читать `getComputedStyle(document.documentElement)` токены `--panel` (фон), `--frame` (рама), `--ink-2` (металл), тёмный для резины/седла; перечитывать при `matchMedia('(prefers-color-scheme: dark)')` change.
- [ ] **tube:** путь из 2 точек — `CylinderGeometry(r1, r0)` ориентированный по отрезку; из 3+ точек — `TubeGeometry(CatmullRomCurve3)` (радиус — среднее r). Скругление стыков — сферы радиуса r на концах труб рамы.
- [ ] **wheel:** обод — `LatheGeometry` профиля 25×20 мм, вращённый в плоскость колеса (ось колеса по z); покрышка — `TorusGeometry(rim/2 + tire/2, tire/2, 24, 128)` + протектор: `InstancedMesh` мелких выступов по окружности (≥ 120); 28 спиц — `InstancedMesh` тонких цилиндров (Ø 2) от фланцев втулки (Ø 50 на z=±flangeZ) к ободу со смещением «2-cross» (каждая спица касается фланца под углом, а не радиально); втулка и ось — цилиндры.
- [ ] **disc:** кольцо Ø diameter с вырезами (`Shape` с `holes` → `ExtrudeGeometry` 2 мм), металл.
- [ ] **ring:** звезда/звезда кассеты — `Shape` с зубьями по окружности радиуса `pitchRadius(teeth)` → `ExtrudeGeometry` 2–3 мм; у звёзд системы — 4–5 вырезов-лучей.
- [ ] **chain:** звенья — `InstancedMesh` (пластина ~12,7×7×2 мм) с шагом 12,7 мм вдоль ломаной `path`, ориентированные по направлению сегмента.
- [ ] **bar:** баранка — `TubeGeometry` по кривой в локальных координатах (центр → вбок до ±width/2 → вперёд на reach → вниз на drop с изгибом назад), Ø 31,8 у центра → Ø 24; обмотка — та же кривая от плеч до концов, тёмный материал чуть толще; ручки тормозов-шифтеров на изгибе (скруглённые боксы).
- [ ] **saddle:** гладкая форма длиной length и шириной width (например, `LatheGeometry`/сплюснутая сфера с сужением к носу), верх в точке `top`, тёмная; рельсы — две тонкие трубки.
- [ ] **box:** скруглённый бокс (`RoundedBoxGeometry` из `three/addons` или `BoxGeometry`).
- [ ] **update(parts):** удалить и `dispose()` старые геометрии/материалы группы, построить новые; камера и контролы сохраняют положение.
- [ ] **Перерисовка:** только когда изменились детали, двигаются контролы (`change`) или размер (`ResizeObserver`); никакого бесконечного `requestAnimationFrame` вхолостую (кроме кадров затухания damping).
- [ ] **Нет WebGL:** если создание рендерера бросает — в контейнер текст «3D недоступно в этом браузере», `update/dispose` — no-op.
- [ ] `npm test && npm run build` → PASS. Коммит `feat: three.js scene for the 3D bike`.
